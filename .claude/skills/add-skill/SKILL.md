---
name: add-skill
description: Add a motion graphics technique (described by the user or extracted from a reference) to the skills library.
---
1. Check `skills/INDEX.md` for an existing skill to extend instead of duplicating.
2. Write `skills/<kebab-name>.md` from `skills/_TEMPLATE.md`: what it looks like, parameters with defaults that match the bible's easing/timing, build steps (code where possible), variations.
3. Add a row to `skills/INDEX.md` and a line to `bible/CHANGELOG.md`.
