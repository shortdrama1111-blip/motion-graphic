# Style Presets

A preset is a complete look (palette, type, finishing, motion feel) that a
project can pick. `08-method.md` applies to every preset. A project brief names
its preset; if none is named, ask or pick the one closest to the brand.

| Preset | Feel | Engine | Source |
|---|---|---|---|
| [light-ui-stroke](light-ui-stroke.md) | Brand's own light UI world, one crisp light stroke threading everything, 2.5D | Canvas 2D | [ref: 2026-11-15-keemfinity-whatsapp-specad] |
| [white-3d-depth](white-3d-depth.md) | Premium white stage, real 3D slabs, fog, DOF, one accent light | three.js | [ref: 2026-11-15-keemfinity-moniepoint-listen] |
