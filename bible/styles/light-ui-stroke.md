# Preset — Light UI Stroke
[ref: 2026-11-15-keemfinity-whatsapp-specad]

- **World:** the brand's own light-mode UI, rebuilt by eye with fictional data — not a dark keynote stage. Light from frame 0.
- **Stage:** brand background colour (WhatsApp example #EFEAE2) + brand pattern/wallpaper drifting at ~10%, soft white key light, faint accent glow 6%.
- **Carrier:** one light drawn as a **crisp stroke, not neon** (see `skills/continuous-light-thread.md`). Bloom ≤6%.
- **UI:** soft drop shadows (~24px), real type at real UI spacing so it reads on a phone. Phone mock: titanium frame 448×924 r70, screen 420×900 r58 on a 2× canvas.
- **Finishing order:** stage → wallpaper → key light/glow → UI + shadows → light strokes → contact shadow (multiply) → spill (soft-light) → bloom 6% → shake → grain 3% → warm vignette 16%.
- **Type:** Inter / Inter Display 400–700. Hero word e.g. 170px/700, letters rise 35 ms apart.
- **Example palette (WhatsApp):** #EFEAE2 stage · #25D366 brand · #1DAA61 deep · #53BDEB ticks · #D9FDD3 out-bubble · #FFFFFF cards · #111B21 text · #667781 secondary · #54656F icons · #FFEECD pill.
- **Format:** 1920×1080, 60 fps.
