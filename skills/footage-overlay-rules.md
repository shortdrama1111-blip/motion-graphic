# Graphics Over Talking-Head Footage
- **Category:** layout / timing · **Engine:** whisper + any · **Source:** [ref: 2026-11-15-starter-kit-prompts]

1. Transcribe with word timings; find the moments that matter.
2. Keep the video untouched (size, fps, audio, cut); graphics only on top.
3. Each graphic is made for what's said: a number → counter, a list → checklist, before/after → comparison. Starts on the exact word.
4. One style across the whole video. Nothing in the first 3 s (the hook).
5. Keep off the face, out of the bottom third (captions), away from the left/right 10%.
6. SFX: tick per list item, counter while numbers roll, chime on last card; quiet under voice; no whooshes on card slides.
7. Transparent export: ProRes 4444 `.mov` with alpha or PNG sequence.
