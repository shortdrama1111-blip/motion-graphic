# Ten Basic Moves
- **Category:** primitives · **Engine:** any · **Source:** [ref: 2026-11-15-starter-kit-prompts]

| Move | Spec |
|---|---|
| Rise | fade in + move up 40px |
| Pop | scale 0.6→1 with slight overshoot (back.out) |
| Count-up | number rolls 0→N (ease-out), `assets/sfx/counter.wav` |
| Checklist tick | lines get a green tick one after another, `tick.wav` each |
| Typewriter | letters appear one by one |
| Slide-in | enters from the right |
| Blur-in | blur → sharp |
| Punch-in | whole frame zooms 15% fast, then holds |
| Reframe | full-screen panel shrinks into a rounded card in the bottom half while a new card appears on top |
| Bar fill | progress bar 0→100%, `fill.wav` |
