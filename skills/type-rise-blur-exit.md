# Type: Mask Rise In / Blur Exit
- **Category:** type · **Engine:** Canvas / CSS / Remotion · **Source:** [ref: 2026-11-15-keemfinity-moniepoint-listen], [ref: 2026-11-15-keemfinity-whatsapp-specad]

- **In:** each word (or letter, 35 ms apart) rises through a clip mask; alpha 0→1 over the first 35% of the rise (prevents ascender tips showing as dots). Ease-out.
- **Hold:** completely still while it must be read.
- **Out:** in place: blur 0→7px, letter-spacing −2→+4px, alpha →0, ~0.3 s. Never sink or slice.
- **Underline variant:** the carrier light draws an underline to the word's end; on exit it collapses into a dot, or grows into a tube ending in an arrowhead that travels on.
